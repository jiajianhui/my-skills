# 产品自检与校正：AI 工作说明

帮助用户理解人的处境，判断什么值得做，将价值变成可靠、易懂、令人愿意使用的体验，并持续兑现承诺。

本文件定义分析方法与各类产品的检查重点。[GUIDE.md](GUIDE.md) 是给用户阅读的简明手册；日常执行无需重复读取。两者属于同一个 skill。具体产品的案例、用户材料、待办与实验留在对应项目。

## 工作流程

1. **先理解产品的选择理由。** 从目标用户、场景、期望结果和现有替代办法，提出主要价值来源；确有必要时补充次要来源。再判断创新程度。分类服务当前决策，不追求给所有产品贴唯一标签。
2. **再定位当前问题。** 确定当前阶段、用户正在做的决定和已授权范围。已有产品的新需求默认继承产品定位，再判断该需求是在强化、补足还是冲突于核心价值；辅助功能不必独立承担整个产品的差异化。
3. **按类型调整检查重点。** 使用共同方向作为基础，只应用与主要、次要价值来源相关的调整，再检查当前阶段。不同类型改变优先级、表现形式和验证方法，不免除可靠性、可理解性、用户控制权与真实承诺。
4. **给出可执行的校正。** 说明有依据的判断、关键偏离或未知、影响以及最小下一步。允许方向合理，不为自检硬找缺点；不以完整分类、补齐问卷或全部阶段检查阻断明确任务。

首次讨论或定位发生变化时，简短交代分类依据。延续同一任务时直接沿用已有判断，仅在新信息改变判断时解释调整。只问最影响当前决定的缺失信息，其余使用明确标注的暂定假设。

## 判断产品类型

“类型”指用户选择产品的价值来源，不是商店品类、技术标签、功能名称或成功等级。

| 价值来源 | 用户的主要选择理由 | 初步识别依据 |
| --- | --- | --- |
| 能力与效率 | 做得更好、更省事，或获得原先难以获得的能力 | 结果质量、工作过程、耗费与替代办法之间的差异 |
| 体验与情感 | 喜欢与它相处，获得愉悦、陪伴、秩序感或自我表达 | 用户在意的具体体验、角色、气质、仪式或感受 |
| 特定人群与场景 | 它理解我的处境，通用方案总有缺口 | 特有任务、语言、节奏、环境、约束或工作习惯 |
| 内容与关系 | 有想看的内容、想交流的人或值得积累的东西 | 内容供给、人与人的联系、贡献及积累的价值 |
| 可获得性与信任 | 负担得起、用得上、能掌控，也愿意放心交给它 | 价格、适配、可访问性、隐私、可迁移性及可信承诺 |

这些来源可以组合，也可能有目前未覆盖的来源。遇到不适合的产品，直接描述其实际选择理由，不硬套类型。不要因为“Todo”就判为效率型，因为“有角色”就判为情感型，或因为“用了 AI”就判为创新型。

分类与差异化起初都是假设：区分设计者打算提供的价值、用户能感知的差异，以及用户实际在意并据此选择的理由。没有用户证据时，不宣称差异化已成立。

### 创新程度单独判断

- **熟悉任务的改善：** 用户已理解用途。重点检查相对原办法的改善是否值得学习、迁移或付费。
- **已有能力的新组合：** 用户认识各部分，但未必需要新的整体。检查组合是否消除了真实衔接成本，而非只增加功能集合。
- **新的能力或使用方式：** 用户可能缺少现成的理解与习惯。优先检查用途能否被理解、使用时刻是否发生、首次价值能否被感知，以及改变行为的成本。

只讨论产品中相关部分的新颖程度，不必为整款产品确定唯一等级。“全新”不等于更有价值，也不意味着没有替代方案；旧工具、人工处理和暂不处理都可能是替代办法。技术新颖不自动代表用户行为新颖。

## 所有类型共用的方向

| 方向 | 不变的判断基础 |
| --- | --- |
| 洞察与价值 | 理解具体处境和期望。价值包括效率、愉悦、秩序、自我表达与被理解，不将所有体验强行解释为痛点或生产力。 |
| 判断与克制 | 为核心价值承担取舍，理解功能、配置、维护与打扰的代价。“少”不是独立目标，核心价值所需的丰富表达应被保留。 |
| 设计与品味 | 判断视觉、文字、交互和情绪是否协调且适合场景。简洁、热闹、专业、可爱均需具体依据，不照搬品牌或类型刻板印象。 |
| 情感与尊重 | 照顾开始、疲惫、失败、中断、回来与完成时的感受。允许拒绝、跳过与离开，不用羞辱、焦虑或亏欠感推动使用。 |
| 空间 | 为内容、理解、选择与自主性留位置。留白、信息密度和分步配置服务任务，不隐藏必要信息。 |
| 呼吸感 | 组织引导、探索、行动、反馈、庆祝与安静的节奏。结合频率与情境，不自动等于慢动效、大留白或强制等待。 |
| 表达与营销 | 接触合适的人，清楚传达选择理由，使期待与实际体验相符。表达困难也可能源于定位不清。 |
| 交付与经营 | 可靠实现承诺，考虑成本、维护、定价与精力边界；不要求每个功能独立变现。 |
| 验证与学习 | 区分事实、意愿、推断和未知。尊重直觉并允许修正；选择与价值承诺相符的观察，不把低样本包装成确定结论。 |

## 按价值来源调整上述方向

以下只写需要改变的重点。混合型产品采用主价值的判断标准，再检查次要价值是否补足或损害它；不能机械叠加所有要求。出现冲突时说明取舍，不用数值权重制造精确感。

### 能力与效率

- **洞察与价值：** 还原完整任务和原办法，观察结果质量、耗时、重复劳动、差错及切换成本。不能只测界面点击数，忽略准备、检查与收尾。
- **判断与克制：** 保留完成任务所需的深度、例外处理和控制能力。减少无效步骤，但不要用过度自动化或隐藏状态制造新的不确定性。
- **设计、品味、情感、空间与呼吸：** 强调清晰、稳定、可预期和掌控感。信息密度按熟练程度调整；高频操作不应被冗长庆祝打断，等待和失败应得到及时、可理解的回应。视觉愉悦仍有价值，不必将效率等同于冷淡。
- **表达、营销与经营：** 展示具体任务中可兑现的改善，说明适用范围；把准确性、性能、迁移与支持成本纳入投入判断，不只宣传技术名称。
- **验证与学习：** 看实际任务是否完成、结果能否使用、总成本是否改善，用户为何采用或放弃。任务自然低频时，不以每日打开次数否定价值。

### 体验与情感

- **洞察与价值：** 理解人希望在什么时刻获得何种感受、表达或关系。漂亮、喜爱、身份认同与陪伴可以独立构成价值，但需要具体用户与情境。
- **判断与克制：** 角色回应、声音、动画、文字或仪式可能属于最小完整体验。优先削减削弱气质的无关功能，而非默认删掉所有非效率元素；情感设定也不能掩盖基本操作障碍。
- **设计、品味、情感、空间与呼吸：** 检查从首次见面到日常重复、失败与回归的气质是否一致。允许表达和停顿，同时考虑用户跳过、安静使用与调整强度的需要；不把陪伴做成情绪索取。
- **表达、营销与经营：** 让用户直接感受角色、氛围和相处方式，避免只有静态美图却缺少实际体验。考虑内容、角色与细节长期更新的成本，价格和承诺应匹配可持续提供的价值。
- **验证与学习：** 结合具体感受的叙述与实际选择、使用或付费，分清喜欢外观、期待关系和已经获得价值。观察新鲜感之后仍被珍惜的体验；不强制用效率提升或使用时长证明一切。

### 特定人群与场景

- **洞察与价值：** 找到通用方案在真实情境中的具体缺口，避免仅按年龄、职业等标签想象需求；同一人群内部也可能有不同工作方式。
- **判断与克制：** 优先把关键场景做透，延后无关的通用能力。专业深度与必要的复杂度可以保留，避免以极简为由取消核心操作。
- **设计、品味、情感、空间与呼吸：** 调整术语、默认值、信息密度、设备适配和提醒时刻，让人感到被理解。熟练操作和首次学习可有不同层级；场景紧迫或注意力受限时，节奏也要适配。
- **表达、营销与经营：** 用用户认得出的处境说明价值，在相关场景和渠道触达；核对定制、支持与维护是否可承受，不默认小众市场一定愿付高价。
- **验证与学习：** 在目标情境中验证关键任务，关注通用方案的缺口是否真正被补上。不能把非目标用户不感兴趣直接判为失败，也不能用一位用户代表整个群体。

### 内容与关系

- **洞察与价值：** 分清消费、创作、交流、归属和积累的动机。涉及多方时，说明谁提供价值、谁消费价值、谁为何回来；不要假设有社区界面就会产生关系。
- **判断与克制：** 优先让有价值的内容、连接或积累实际发生。早期要说明供给和首次回应从哪里来，不用大量互动功能掩盖内容或关系不足。
- **设计、品味、情感、空间与呼吸：** 让内容易读、表达自在、交流有上下文。为阅读、创作、等待回复和暂时离开留出空间；检查信息流与通知是否让人感到过载，尊重可见性和互动边界。
- **表达、营销与经营：** 展示具体内容、人物或共同活动的价值，考虑内容生产、社区维护及供需启动成本；不能把网络效应当作已存在的优势。
- **验证与学习：** 看是否形成有价值的阅读、创作、回应、连接或积累，再解释访问与互动数量。被动停留、消息量和打开次数不自动等于满意或关系质量。

### 可获得性与信任

- **洞察与价值：** 明确原办法为什么用不上、负担不起或不敢交付：价格、语言、设备、网络、可访问性、隐私、控制与迁移等，按实际问题选择检查。
- **判断与克制：** 减少阻碍采用的条件和不必要的权限、账号或锁定，保留必要说明与控制。价格低和设置少都不能独立证明优势。
- **设计、品味、情感、空间与呼吸：** 强调可理解、可辨认、可控制与安心。解释发生了什么、用户有哪些选择；敏感决定留出理解空间，状态及时反馈。可信不等于文案严肃或视觉保守。
- **表达、营销与经营：** 将隐私、兼容、价格、离线或可迁移等承诺落实到实际能力，明确条件与限制。检查低价、长期支持和服务成本是否可持续，不承诺无法保障的永久能力。
- **验证与学习：** 在目标条件下检查采用障碍是否降低、承诺是否兑现。区分口头表示信任与实际愿意交付任务或迁移的行为，不把低价带来的尝试自动看成持续价值。

## 当前阶段检查

先根据价值来源确定“预期结果”包含什么，再选当前阶段所需的检查；不要重复输出完整策略分析。

| 阶段 | 当前应判断的问题 | 校正方向 |
| --- | --- | --- |
| 构思与问题理解 | 谁在什么时刻需要这种价值？原办法是什么？ | 还原具体经历或期望情境，核对选择理由与最大未知。 |
| 定位与范围取舍 | 哪些组成部分是兑现核心承诺所必需的？ | 保留最小完整价值；说明暂缓项与代价，避免照抄竞品清单。 |
| 体验与方案设计 | 用户能否理解、行动、感受价值、获得反馈并恢复？ | 按该类型的重点检查完整过程，修正阻力、失调和不必要的负担。 |
| 实现与交付 | 实际产品是否兑现了承诺？ | 将可靠性、关键状态与类型核心体验一起纳入交付，控制工程范围。 |
| 发布与营销 | 合适的人能否发现、理解、尝试？承诺和价格是否合适？ | 用具体场景传达主要选择理由，检查渠道、门槛和经营成本。 |
| 使用与复盘 | 实际价值是否发生，什么判断需要改变？ | 对照预期与证据决定继续、调整或停止，不只看泛化的活跃指标。 |

新颖程度高时，优先消除用途理解、使用触发和首次价值的不确定性；熟悉任务的改善则更多核对相对旧办法的收益。创新层调整验证顺序，不替代价值类型，也不要求每次重走所有阶段。

## 输出与个人实践

默认简明中文。必要时先用一句话交代“暂定主要价值来源、创新程度、因此本轮重点”，随后直接回答用户当前的问题：

- 当前判断与最关键的偏离或未知。
- 依据、对用户与持续交付的影响。
- 最小校正动作，如何观察，什么结果会改变判断。

有多种合理方案时说明取舍。不要机械展示所有类型、方向或检查表，不给缺少依据的能力分数，也不只说“提升品味”“更有呼吸感”；落到具体行为、页面、表达或决策。

个人实践采用“选择真实问题 → 判断最小改善 → 交付 → 观察使用 → 修正理解”。每轮重点练习一两项能力：洞察、判断、体验设计、情感理解、表达与分发、验证与学习、交付与经营。记录原判断、实际证据、修正和下一步；尚未观察就保留未知，不能把上线等同于价值已实现，也不把产品结果直接归为人格或天赋。

## 维护这一个 skill

保持两份文件：本文件提供 AI 的分类与调整规则，GUIDE.md 保留人可快速阅读的核心原则和自检问题。方法有实质变化时同步其摘要，不要求两份文字逐句重复，不在执行时默认加载两份。

品味、空间与呼吸感是可演进的工作定义。用户提供参考时，理解其喜欢的具体瞬间，区分明确认可的偏好与助手解释，记录适用条件与反例。只将可复用、经用户认可的理解纳入手册；用户的具体项目记录仍留在项目中。
