# 产品自检与校正：个人手册

理解人的处境，判断什么值得做，把价值变成可靠、易懂、令人愿意使用的体验，并让这件事持续下去。

这份手册用来在关键决策时校准方向。每次只看当前阶段最相关的问题，无须完整检查一遍，也不必给自己打分。

## 先确认：用户为什么选择它？

在讨论新产品，或重新判断产品方向时，先想清楚四件事：

1. 谁会在什么场景选择它？他现在用什么办法，包括暂时不处理？
2. 最主要的选择理由是什么？用户需要接受多大程度的新方式？
3. 为了兑现这个理由，哪些体验必须做好，哪些可以放下？
4. 最不确定的判断是什么，怎样观察它是否成立？

选择理由可能来自能力与效率、体验与情感、特定人群与场景、内容与关系，或可获得性与信任。它们可以组合；类型只是帮助取舍的视角，差异化是否成立还要看用户是否感知、在意并据此选择。

创新程度另看：熟悉任务的改善，需要证明改善值得采用；已有能力的新组合，需要证明衔接更有价值；新的能力或使用方式，需要先确认用途、使用时刻和首次价值。新颖不自动等于有价值。

已有产品的新需求，先看它在强化、补足还是冲突于原来的核心价值，不必每次重做整个产品的定位。

## 各阶段自检

| 阶段 | 我需要问自己什么？ |
| --- | --- |
| 构思与问题理解 | 我理解的是具体人的处境，还是自己的想象？现在的办法为什么不够？ |
| 定位与范围取舍 | 本轮最重要的价值是什么？哪些必须做到，哪些值得暂缓？ |
| 体验与方案设计 | 用户能否理解、行动、获得反馈并恢复？他是否实际感受到了承诺的价值？ |
| 实现与交付 | 实际产品是否兑现方案？关键状态、性能、数据与核心体验是否可靠？ |
| 发布与营销 | 合适的人在哪里？他能否看懂选择理由？宣传、价格与真实体验是否一致？ |
| 使用与复盘 | 什么实际发生了？哪一个判断被支持或推翻？该继续、调整还是停止？ |

## 贯穿各阶段的方向

- **洞察与价值：** 自己的体验可以提出假设，用户的具体经历帮助修正理解。价值包含效率、愉悦、秩序感、自我表达和被理解。
- **判断与克制：** 理解功能、选项、维护与打扰的代价，为重点承担取舍。围绕核心价值决定丰富还是简洁；“少”本身不是目标。
- **设计与品味：** 辨别比例、文字、视觉、交互与情绪是否协调，能解释它们为什么适合这里。简洁、鲜明、热闹、可爱都可能有品味。
- **情感与尊重：** 照顾开始、疲惫、失败、中断、回来与完成时的感受。可以鼓励和庆祝，也允许安静使用、拒绝和离开。
- **空间：** 为内容、理解、选择与自主性留下位置，不一次要求用户处理所有信息。留白服务层级与任务，不掩盖必要信息。
- **呼吸感：** 组织引导、探索、行动、反馈、庆祝与安静的节奏。它存在于动效、文字、信息密度和打扰频率里，不等于慢或空。
- **表达与营销：** 让合适的人发现、理解和尝试，让期待与体验相符。说不清价值时，也回头检查定位。
- **交付与经营：** 用实现能力兑现承诺，兼顾维护、成本、定价和自己的精力，让产品可以持续存在。
- **验证与学习：** 尊重直觉，也允许它被修正。区分用户的期待和实际行为，不把好评、下载、付费与持续使用混为一谈。

## 不同类型，怎样改变重点？

| 主要选择理由 | 特别值得守住什么？ | 不能只凭什么判断成功？ |
| --- | --- | --- |
| 能力与效率 | 结果质量、整个任务的成本、可靠性和掌控感 | 步骤变少、功能变多或每日打开次数 |
| 体验与情感 | 独特且一致的相处体验、表达与感受，以及用户的自主性 | 可爱、第一眼惊喜或停留时长 |
| 特定人群与场景 | 对真实约束的理解、关键场景的适配和必要深度 | 通用功能数量或非目标用户的评价 |
| 内容与关系 | 内容质量、有意义的交流、贡献与积累 | 消息量、浏览量或被动停留 |
| 可获得性与信任 | 采用障碍真正降低、承诺可兑现、用户能理解和掌控 | 价格低、设置少或口头表示信任 |

共同方向不变，优先级、表现形式和观察方法随价值主张调整。例如角色回应可能是情感产品的核心，而高频工作工具更需要快速反馈；两者都需要可靠、易懂并尊重用户。

## 每次只做一个具体校正

说清楚：现在的判断是什么，依据在哪里，最关键的偏离或未知是什么，下一步具体改什么、观察什么。

可以得出“方向合理”。不要为了自检寻找缺点，也不要用“提升品味”“更有呼吸感”代替具体决策。

用“选择真实问题 → 判断最小改善 → 交付 → 观察使用 → 修正理解”完成一次实践。每轮重点练习一两项能力：洞察、判断、体验设计、情感理解、表达与分发、验证与学习、交付与经营。

复盘只需记下原来的判断、实际证据、修正了什么和下一步。没有观察就保留未知，上线只代表交付完成。

## 这份手册可以慢慢长出来

品味、空间、呼吸感的个人理解可以继续形成。看到喜欢的作品，先记住具体哪个瞬间打动自己、为什么、适合什么场景，再通过自己的产品检验。

把确认过的理解补进相应段落，遇到反例就修订。具体项目的反馈和实验留在项目里，这里沉淀能够复用的判断。

与 AI 讨论时，可以说：“用 `$product-self-check`，先判断这个产品的主要价值类型，再帮我检查当前这个问题。”AI 的具体工作规则在同目录 [SKILL.md](SKILL.md)。
